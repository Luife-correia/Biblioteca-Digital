# 📖 Biblioteca Digital

Este projeto foi desenvolvido como parte da disciplina de **Programação Web**.  
O objetivo é simular uma **Biblioteca Digital**, permitindo que usuários naveguem pelas páginas, conheçam os serviços e entrem em contato com a instituição.

## 🚀 Tecnologias utilizadas
- **HTML5**: estruturação das páginas.
- **CSS3**: estilização e layout responsivo.

## 📂 Estrutura do projeto
- `index.html` → Página inicial da biblioteca.
- `style.css` → Arquivo de estilos principais.
- `contato.html` → Página de contato.

## 🎯 Objetivos
- Praticar conceitos de **HTML semântico**.
- Aplicar **CSS puro** para estilização e responsividade.
- Criar uma experiência simples e intuitiva para o usuário.

## 📌 Funcionalidades
- Página inicial com informações da biblioteca.
- Página de contato para interação com os usuários.
- Layout responsivo e estilizado apenas com CSS.
